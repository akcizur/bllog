Visual calm is often a proportion problem before it is a style problem.

A good interface gives every element enough room to be understood without making the page feel empty.

## Start with the measure

Constrain long-form text to a predictable reading width. The eye should know where the next line begins.

## Then remove friction

Fewer containers and fewer competing treatments make the remaining components easier to align, maintain and use.
